ADM now runs on Windows. This release adds the Windows installer and a portable build, and the project's documentation and privacy policy.

## Downloads

| File | What it is |
|---|---|
| `adm-0.2.1-windows-x64-setup.exe` | Windows installer. Per user, no administrator rights. |
| `adm-0.2.1-windows-x64-portable.zip` | Windows, no installer and no browser registration. |
| `adm-0.2.1-linux-x86_64.tar.gz` | Linux: the app, `adm-dl` (command line and MCP server) and an installer. Needs WebKitGTK 4.1. |
| `adm-extension-0.5.0.zip` | The browser extension for Chrome, Edge, Brave and other Chromium browsers (load unpacked). |
| `SHA256SUMS`, `SHA256SUMS-windows.txt` | Checksums. |

## Windows

- The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Choose More info, then Run anyway.
- The browser extension starts ADM on Windows too. The installer registers a small launcher with Chrome, Edge, Brave and Chromium, and removes it when ADM is uninstalled.
- The Windows build is checked by automated tests that install it, start it from the browser launcher, download a file with a checksum, and uninstall it. It has had less everyday use than the Linux build.

## Also in this release

- A rewritten README, and a privacy policy (`PRIVACY.md`).
- The browser extension is unchanged (0.5.0).

Linux users upgrading: run `./install.sh` from the new tarball. The extension does not need reinstalling.
