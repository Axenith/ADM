First release of ADM: a fast, lightweight download manager with multi-connection speed, pause and resume, and browser integration, in a single ~5 MB app.

## Downloads

| File | What it is |
|---|---|
| `adm-0.1.0-linux-x86_64.tar.gz` | The app (`adm`), the command-line tool (`adm-dl`) and an installer. Needs WebKitGTK 4.1. |
| `adm-extension-0.3.0.zip` | The browser extension for Chrome, Brave and other Chromium browsers (load unpacked). |
| `SHA256SUMS` | Checksums of the two files above. |

**Install:** `tar xzf adm-0.1.0-linux-x86_64.tar.gz && cd adm-0.1.0-linux-x86_64 && ./install.sh`, then search for "ADM" in your launcher. See the [README](https://github.com/Axenith/ADM#install) for the extension and for building from source.

## What's in it

- Multi-connection downloads that split the busiest range as connections free up, resume that survives crashes, and detection of a file that changed on the server.
- A download queue, speed limit, retries, and refreshing of expired links.
- A "New download" window (name, category, folder with Browse, free space, connections) that remembers your last folder, and one window for a batch of links.
- A tray icon (closing the window frees the web view's memory), a single running copy, dark and light themes.
- Browser extension: sends browser downloads to ADM and never loses one if ADM is off; opt-in **browser monitoring** lists the videos on a page; **grab all links**; "don't capture from this site".

## Known limits

- Linux only so far (tested on Arch with Hyprland). Windows and macOS are not verified.
- Streamed video (HLS/DASH, used by most video sites) is not supported yet; only videos that are a single file are listed.
- The extension is loaded unpacked until it is on the Chrome Web Store.
