ADM now trusts the Chrome Web Store version of its browser extension.

## Downloads

| File | What it is |
|---|---|
| `adm-0.2.2-windows-x64-setup.exe` | Windows installer. Per user, no administrator rights. |
| `adm-0.2.2-windows-x64-portable.zip` | Windows, no installer and no browser registration. |
| `adm-0.2.2-linux-x86_64.tar.gz` | Linux: the app, `adm-dl` (command line and MCP server) and an installer. Needs WebKitGTK 4.1. |
| `adm-extension-0.5.0.zip` | The browser extension for Chrome, Edge, Brave and other Chromium browsers (load unpacked). |
| `SHA256SUMS`, `SHA256SUMS-windows.txt` | Checksums. |

## What changed

- The browser launcher that lets the extension start ADM now also accepts the extension published on the Chrome Web Store, in addition to the one loaded from this repository. Update ADM to this version before installing the Store extension, so it can start ADM automatically.
- No other changes. The extension is unchanged (0.5.0).
