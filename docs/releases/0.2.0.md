A big step for the browser extension, a new main window, and ADM for AI agents.

## Downloads

| File | What it is |
|---|---|
| `adm-0.2.0-linux-x86_64.tar.gz` | The app (`adm`), the command-line tool and MCP server (`adm-dl`) and an installer. Needs WebKitGTK 4.1. |
| `adm-extension-0.5.0.zip` | The browser extension for Chrome, Brave and other Chromium browsers (load unpacked). |
| `SHA256SUMS` | Checksums of the two files above. |

**Install or update:** `tar xzf adm-0.2.0-linux-x86_64.tar.gz && cd adm-0.2.0-linux-x86_64 && ./install.sh`. Then reload the extension at `chrome://extensions` (or `brave://extensions`); if you had an older one loaded, remove it, because the new one has a different ID. See the [README](https://github.com/Axenith/ADM#install).

## What's new

**New main window.** A sidebar with *Library* (All Downloads, Incomplete, Completed) and *File types* (Documents, Compressed, Music, Video, Programs) with live counts, and a toolbar: **New**, **Clear** (finished downloads leave the list, their files stay), **Sort**, **Settings**, search (`Ctrl+F`) and a menu (pause all, resume all, retry or clear failed).

**ADM starts itself from the browser.** If ADM is not running, *Download with ADM*, the popup's download button, *Grab links* and browser downloads that ADM would take now open ADM in the tray and hand the download over. It can be turned off in the extension's options. If ADM cannot be started, the browser downloads as usual.

**ADM for AI agents.** `adm-dl mcp` is a Model Context Protocol server (Claude Code, opencode, Gemini CLI, Codex, Cursor): several connections, resume, checksum check, and long downloads that report back with a job id instead of timing out. `adm-dl <url> --json` gives any agent with a shell one JSON line when done. No GUI needed. See [docs/AGENTS.md](https://github.com/Axenith/ADM/blob/main/docs/AGENTS.md).

**A smarter extension (0.5.0).**
- You choose what it takes over: file types and a size threshold, set in ADM's Settings.
- With browser monitoring on, downloads are repeated with the headers and cookies the browser really sent; downloads that cannot be repeated (a file made by a form) stay with the browser.
- Pieces of YouTube-style streams are no longer listed as videos.
- *Grab links* (Alt+Shift+G): a tab for the page's links and one for everything the page loads, wildcard (`*.jpg`) and `/regex/` filters, an ad and tracker filter, invert selection.

**Clearer errors.** A failed download now says why, for example "Not found on the server (HTTP 404)" instead of one vague message.

## Known limits

- Linux only so far (tested on Arch with Hyprland). A Windows build is planned.
- Streamed video (HLS/DASH, used by most video sites) is not supported yet.
- The extension is loaded unpacked until it is on the Chrome Web Store. Its pinned ID is only recognised by this ADM, not by a store copy yet.
